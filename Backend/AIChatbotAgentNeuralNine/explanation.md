## Επισκόπηση

Το αρχείο main.py περιέχει τον κώδικα για τη δημιουργία και την εκπαίδευση ενός απλού AI chatbot. Ο στόχος του chatbot είναι να αναγνωρίζει την πρόθεση (intent) του χρήστη από ένα μήνυμα και να απαντά αναλόγως. Για παράδειγμα, αν ο χρήστης πει "Γεια σου", η πρόθεση είναι "χαιρετισμός" και το chatbot απαντά με ένα μήνυμα χαιρετισμού.

> Ο κώδικας αποτελείται από δύο κύριες κλάσεις:

> > 1.  ChatbotModel: Ένα **νευρωνικό δίκτυο** που "μαθαίνει" να κατηγοριοποιεί τα μηνύματα του χρήστη.

> > 2.  ChatbotAssistant: Η κλάση που χειρίζεται ολόκληρη τη διαδικασία, από την προετοιμασία των δεδομένων μέχρι την επεξεργασία των μηνυμάτων.

2. Η Κλάση ChatbotModel
   Αυτή η κλάση ορίζει το νευρωνικό δίκτυο του chatbot. Είναι η "καρδιά" του μοντέλου, όπου λαμβάνει χώρα η "μάθηση".

Python

`class ChatbotModel(nn.Module):
def **init**(self, input_size, output_size):
super(ChatbotModel, self).**init**()

        self.fc1 = nn.Linear(input_size, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, output_size)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.relu(self.fc2(x))
        x = self.dropout(x)
        x = self.fc3(x)

        return x`

- class ChatbotModel(nn.Module): Ορίζει μια κλάση που κληρονομεί από την nn.Module της PyTorch. Αυτή η κληρονομιά είναι απαραίτητη για να λειτουργήσει ως νευρωνικό δίκτυο.

- def **init**(self, input_size, output_size): Ο κατασκευαστής της κλάσης. Καθορίζει τα layers (στρώματα) του δικτύου.

- self.fc1 = nn.Linear(input_size, 128): Το πρώτο πλήρως συνδεδεμένο στρώμα (fully connected layer). Παίρνει ένα διάνυσμα εισόδου με μέγεθος input_size και παράγει ένα διάνυσμα εξόδου με 128 στοιχεία.

- self.fc2 = nn.Linear(128, 64): Το δεύτερο στρώμα. Παίρνει 128 εισόδους και δίνει 64 εξόδους.

- self.fc3 = nn.Linear(64, output_size): Το τελικό στρώμα εξόδου. Παίρνει 64 εισόδους και δίνει έναν αριθμό εξόδων ίσο με το πλήθος των πιθανών προθέσεων (intents) του chatbot (output_size).

- self.relu = nn.ReLU(): Η συνάρτηση ενεργοποίησης ReLU. Εφαρμόζεται μετά από κάθε στρώμα για να εισαχθεί μη-γραμμικότητα στο δίκτυο, κάτι που του επιτρέπει να "μάθει" πιο πολύπλοκα μοτίβα.

- self.dropout = nn.Dropout(0.5): Ένας μηχανισμός για την αποφυγή της υπερεκπαίδευσης (overfitting). Κατά την εκπαίδευση, απενεργοποιεί τυχαία το 50% των νευρώνων σε κάθε στρώμα.

- def forward(self, x): Ορίζει τη διαδρομή προς τα εμπρός (forward pass) του δικτύου. Περιγράφει πώς τα δεδομένα περνούν μέσα από τα στρώματα.

- x = self.relu(self.fc1(x)): Η είσοδος x περνά από το πρώτο στρώμα και μετά εφαρμόζεται η συνάρτηση ReLU.

- x = self.dropout(x): Εφαρμόζεται το dropout.

- Η διαδικασία επαναλαμβάνεται για το δεύτερο στρώμα.

- x = self.fc3(x): Το αποτέλεσμα περνά από το τελικό στρώμα, το οποίο δίνει τις τελικές προβλέψεις για την πρόθεση του χρήστη.

- Μέθοδοι για την Επεξεργασία Φυσικής Γλώσσας (NLP)
  @staticmethod def tokenize_and_lemmatize(text):

nltk.word_tokenize(text): Αυτή η γραμμή παίρνει μια πρόταση και τη χωρίζει σε λέξεις (tokens), π.χ., "What's up?" γίνεται ['What', "'s", 'up', '?'].

lemmatizer.lemmatize(word.lower()): Αυτή η διαδικασία ονομάζεται λεμματισμός. Μετατρέπει κάθε λέξη στην θεμελιώδη μορφή της. Για παράδειγμα, "running" γίνεται "run", "better" γίνεται "good". Αυτό είναι σημαντικό γιατί επιτρέπει στο chatbot να αναγνωρίζει την ίδια λέξη ανεξάρτητα από το πώς είναι γραμμένη.

def bag_of_words(self, words):

Αυτός ο αλγόριθμος ονομάζεται Bag of Words (Σακί Λέξεων). Δημιουργεί ένα διάνυσμα από 1 και 0, όπου κάθε θέση του διανύσματος αντιστοιχεί σε μια λέξη από το συνολικό λεξιλόγιο του chatbot.

Εάν μια λέξη από την είσοδο του χρήστη υπάρχει στο λεξιλόγιο, η αντίστοιχη θέση στο διάνυσμα γίνεται 1. Διαφορετικά, παραμένει 0. Για παράδειγμα, αν το λεξιλόγιο είναι ['hi', 'hello', 'bye'] και ο χρήστης πει "hi", το διάνυσμα είναι [1, 0, 0].

- Μέθοδοι για την Προετοιμασία των Δεδομένων
  def parse_intents(self): Διαβάζει το αρχείο intents.json και το αναλύει.

Δημιουργεί ένα λεξιλόγιο (self.vocabulary) από όλες τις λέξεις που βρίσκονται στα patterns.

Αποθηκεύει τις προθέσεις (self.intents) και τις αντίστοιχες απαντήσεις (self.intents_responses).

Δημιουργεί μια λίστα self.documents που περιέχει ζεύγη από τις λέξεις του pattern και την αντίστοιχη πρόθεση.

def prepare_data(self):

Χρησιμοποιεί τον αλγόριθμο Bag of Words για να μετατρέψει τα patterns από το αρχείο intents.json σε αριθμητικές αναπαραστάσεις (self.X) που μπορεί να καταλάβει το νευρωνικό δίκτυο.

Δημιουργεί έναν πίνακα (self.y) με τους αριθμητικούς δείκτες για κάθε πρόθεση. Αυτά είναι τα labels (ετικέτες) που θα προσπαθήσει να προβλέψει το νευρωνικό δίκτυο.

- Μέθοδοι για την Εκπαίδευση και την Αποθήκευση/Φόρτωση του Μοντέλου
  def train_model(self, batch_size, lr, epochs): Αυτή είναι η διαδικασία εκπαίδευσης του νευρωνικού δικτύου.

Τα δεδομένα (self.X, self.y) μετατρέπονται σε tensors της PyTorch.

Δημιουργείται ένας DataLoader για να χωρίσει τα δεδομένα σε μικρότερες παρτίδες (batch_size).

Ορίζεται το κέρδος (loss function): `nn.CrossEntropyLoss()`. Αυτή είναι μια μαθηματική φόρμουλα που μετρά πόσο λάθος είναι οι προβλέψεις του δικτύου. **Στόχος είναι να ελαχιστοποιηθεί αυτό το κέρδος.**

Ορίζεται ο **βελτιστοποιητής** (optimizer): `optim.Adam()`. Αυτός είναι ο αλγόριθμος που χρησιμοποιείται για να **ενημερώνει τα βάρη** του δικτύου με τέτοιον τρόπο ώστε να μειωθεί το κέρδος.

Η διαδικασία της εκπαίδευσης επαναλαμβάνεται για έναν συγκεκριμένο αριθμό εποχών (epochs). Σε κάθε εποχή, το δίκτυο βλέπει όλα τα δεδομένα.

`loss.backward()`: Υπολογίζει τις **παραγώγους** (gradients) του κέρδους σε σχέση με τα βάρη του δικτύου.

`optimizer.step()`: Ενημερώνει τα βάρη του δικτύου με βάση τις παραγώγους, προσαρμόζοντας τα για να γίνουν οι **προβλέψεις καλύτερες**.

`def save_model(...) και def load_model(...):` Αυτές οι μέθοδοι αποθηκεύουν και φορτώνουν το εκπαιδευμένο μοντέλο σε αρχεία, ώστε να μην χρειάζεται να εκπαιδευτεί ξανά κάθε φορά.
